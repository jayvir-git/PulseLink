# Workflow diagram

The README uses static SVGs generated by Pele 1.13.0. The renderer is a documentation development dependency; the application does not load Pele.

Edit `workflow.mmd`, then run from this directory:

```sh
npm ci
npm run build
```

Commit the source, renderer, lockfile and both generated SVGs. Colors follow PulseLink's green palette, with separate light and dark variants selected by the README picture element. Arial is used for portable rendering without remote font requests. The Mermaid source supplies an accessible title and description; the README also provides alt text and a prose workflow.
